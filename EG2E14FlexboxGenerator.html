Quick Reference
justify-content Controls alignment on the main axis.
align-items Controls alignment on the cross axis.
flex-wrap Allows items to move onto the next line.
gap Adds space between rows and columns.
flex-grow Lets an item expand to fill available space.
order Changes the visual order of items.
Flexbox Axis Reference

X axis = horizontal  |  Y axis = vertical

row: X is the main axis, Y is the cross axis

column: Y is the main axis, X is the cross axis

Container Properties

display
Sets the element as a flex container.
flex-direction
Sets the main axis direction.
flex-wrap
Wraps items when they no longer fit.
justify-content
Aligns items along the main axis.
align-items
Aligns items along the cross axis.
align-content
Aligns wrapped rows or columns. Available only when flex-wrap is wrap or wrap-reverse.
gap
Adds space between items.

Item Properties
Selected item
Click an item in the preview to edit its properties.
align-self
Override the container's align-items for this specific item.
flex-grow
How much this item grows relative to siblings when there's extra space. 0 = no growth.
flex-shrink
How much this item shrinks relative to siblings when space is tight. 1 = shrinks normally.
flex-basis
The initial size before free space is distributed. Use Auto or set a specific px value.
order
Changes the visual order without altering the HTML source. Lower values appear first.
width and height (px)
Set the selected item's width and height, or use Auto to leave either dimension flexible.
